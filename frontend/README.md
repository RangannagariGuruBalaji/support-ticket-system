# Support Ticket System - Frontend

This is the React frontend application for the Support Ticket Management System.

## Technology Stack
- **React.js 18**
- **Vite** (Build Tool)
- **React Router v6**
- **Axios** (HTTP Client)
- **Vanilla CSS** (Custom dark modern glassmorphism design system)

## Setup & Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Open browser at `http://localhost:3000`.
